    展开复现步骤与 usage 计量

    先通过 MetaRefine「工具」页接通 WorkBuddy。每个案例的关闭组与开启组都从同一份 seed 复制到各自全新空白工作区，并使用新会话；方案均为 standard，固定模型 mr-deepseek（DeepSeek Flash），context_optimization 与 tool_output_reduction 两项同时关闭或开启。可以在同一当前 0.1.92 安装上复现新的一对；表中历史关闭组版本 0.1.90/0.1.91 是原始对照来源，不要求客户取得旧版本。其他客户端暂停时，也可记录 MR 本机累计 input/output Token 的运行前后差值。

    1. 01将同一案例 seed 分别复制到 OFF 与 ON 两个独立空白工作区，并开启新 WorkBuddy 会话。
    2. 02在对应 WorkBuddy 环境运行 prompts 文件中的完整提示，保存 answer.json，并按 cases.json 的 expected 核验。
    3. 03按复现文件逐个案例/阶段统计完整会话 usage；不把不同阶段的日志混在一起。

    CLI 高级方式需使用自己在 MetaRefine「工具」页接入时配置的插件与 MCP 路径；命令保留这两个参数，不省略为独立 CLI 调用。

    # 先把解压目录绝对路径、案例和阶段设好；OFF 与 ON 分别执行
$packageRoot = (Resolve-Path 'C:\absolute\path\to\MetaRefine-Token-Reproduce-0.1.92').Path
$caseId = 'orders-regression-green-1800'
$phase = 'off' # 另开新会话，以 on 阶段重跑
$outer = Split-Path $packageRoot -Parent
$workspace = Join-Path $outer "$caseId-$phase-workspace"
$usageDir = Join-Path $outer 'usage'
$usageFile = Join-Path $usageDir "$caseId-$phase.jsonl"
$seedDir = Join-Path $packageRoot "seed\$caseId"
$taskPrompt = Get-Content -LiteralPath (Join-Path $packageRoot "prompts\$caseId.txt") -Raw
$wbCli = Join-Path $env:LOCALAPPDATA 'Programs\WorkBuddy\resources\app.asar.unpacked\cli\dist\codebuddy-lite-wb.mjs'
# 填入你自己在 MetaRefine「工具」页接入 WorkBuddy 时使用的插件目录和 MCP 配置路径；不要分享配置或密钥。
$mrPluginDir = '填入你自己的 MR WorkBuddy 插件目录'
$mrMcpConfig = '填入你自己的 MR WorkBuddy MCP 配置路径'
if (Test-Path -LiteralPath $workspace) { throw 'Choose a new empty workspace path for this run' }
New-Item -ItemType Directory -Path $workspace, $usageDir -Force | Out-Null
Copy-Item -Path (Join-Path $seedDir '*') -Destination $workspace -Recurse
$wbArgs = @('-p', '--output-format', 'stream-json', '--plugin-dir', $mrPluginDir, '--mcp-config', $mrMcpConfig, '--model', 'custom-local:mr-deepseek', '--tools', 'default', '--allowedTools=Bash,Read,Write', $taskPrompt)
Push-Location $workspace
try { node $wbCli @wbArgs > $usageFile } finally { Pop-Location }

# 只读本案例、此阶段的日志，取最后一条 type=result.usage
$lastUsage = $null
foreach ($line in Get-Content -LiteralPath $usageFile) {
  $event = $line | ConvertFrom-Json
  if ($event.type -eq 'result') { $lastUsage = $event.usage }
}
if ($null -eq $lastUsage) { throw 'Missing final result usage' }
$inputTokens = [long]$lastUsage.input_tokens
$outputTokens = [long]$lastUsage.output_tokens
"input_tokens=$inputTokens"
"output_tokens=$outputTokens"
"total_tokens=$($inputTokens + $outputTokens)"

    代码只读取指定案例/阶段 JSONL 中最后一条 result.usage；total 为 input + output。缓存读取已计入 input_tokens，不再重复相加。将提示文件和 usage 日志保存在案例工作区之外；不要分享原始 JSONL。
